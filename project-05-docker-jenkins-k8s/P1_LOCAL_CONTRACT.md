# P1 Local Contract — Deploy your code on a Docker Container using Jenkins on AWS

## Allowed local path

Students may inspect checked-in source, fixtures, and documentation and may run the local validation scripts
declared in the active-integrity manifest.

## Prohibited operations

Do not use credentials, provider CLIs, cloud endpoints, deployment commands, destructive commands, or
production/shared environments. The contract fails closed: when a required local prerequisite is unavailable,
stop and ask the instructor.

## Observable outcome

A successful local validation run reports the project identifier, confirms the active documents and fixtures,
and records a source-only PASS result.
